# 油站价哨 · 加油站优惠价格智能监控平台

把「每天在多个合作平台逐个翻查各加油服务商的优惠券报价」收敛成一个看板：自动找出被竞品抢走最低价的位置，给出调价建议与运营日报。

> 这是一个个人作品集演示项目。页面中的价格全部由浏览器本地生成（模拟数据），不抓取任何平台数据，也不代表任何真实报价。

## 功能

- **价格总览**：4 项核心指标、抢占预警条、平台内各服务商价格对比、近 7 天走势、各平台竞争态势、优先处理建议（可一键采纳调价）
- **加油站管理**：搜索、新增 / 编辑 / 删除、合作状态、数据覆盖度
- **价格录入 / 导入**：手动录入、CSV / Excel 批量导入、粘贴导入、CSV 模板下载、价格记录、调价留痕
- **AI 智能中心**：价格预警、异常突变、调价建议、自动日报
- **设置**：预警 / 突变阈值、操作人、平台 / 服务商 / 油品维护、导出 JSON / CSV、重置

## 快速开始

无需安装、无需构建：

```bash
# 方式一：直接双击 index.html
# 方式二：起一个本地静态服务
python -m http.server 8765
# 打开 http://localhost:8765/index.html
```

首次打开会自动生成 7 天演示数据（3,360 条），存储在浏览器 `localStorage`（键名 `oil_sentry_v4`）。

## 业务模型

```
合作平台（哈啰 / 高德 / 百度 / 滴滴）  ×  加油站（线下履约）  ×  加油服务商（我方与竞品）
```

价格按 `加油站 + 油品 + 平台 + 服务商` 四维存储，同一维度取最新日期的记录。

## 规则（默认值，可在设置中调整）

| 规则 | 口径 |
| --- | --- |
| 价格预警 | 我方价高于同平台竞品最低价且价差 > 0.08 元/L，按 ≥0.2 / ≥0.12 / 其他分三级 |
| 异常突变 | 同一站 + 油品 + 平台 + 服务商，近两个不同日期涨跌幅 ≥ 0.1 元/L |
| 调价建议 | 同平台竞品最低价 −0.02 元，下限为成本 +0.03 元，低于下限提示「审慎跟价」 |
| 调价留痕 | 我方价格变动 ≥ 0.005 元时记录原价、新价、幅度、平台、操作人、来源 |

## 数据与合规

- 合作平台没有公开的服务商报价 API，爬取存在封号与合规风险，因此一期采用**人工录入 + CSV / Excel 导入**。
- 代码中没有任何 `fetch` / `XMLHttpRequest` 调用，演示数据完全在本地生成，来源标记为「演示数据」。
- 数据只存在本机浏览器，清除缓存或更换浏览器即丢失。

## 技术栈

- 原生 HTML / CSS / JavaScript（ES6），无构建工具、无后端
- [Chart.js 4.4.1](https://www.chartjs.org/)（近 7 天走势，加载失败自动降级为文字提示）
- [SheetJS (xlsx) 0.18.5](https://sheetjs.com/)（Excel 解析）
- 浏览器 `localStorage` 持久化
